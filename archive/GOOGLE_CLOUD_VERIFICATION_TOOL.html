Step 4: Common Issues & Solutions

❌ "This API project is not authorized to use this API"

Solution: Enable the Maps Static API in Google Cloud Console

1. Go to APIs & Services > Library 2. Search for "Maps Static API" 3. Click on it and press "Enable"

❌ "API key not valid. Please pass a valid API key."

Solution: Check API key restrictions and billing

1. Verify billing is enabled 2. Check API key restrictions in Credentials 3. Wait 5-10 minutes for changes to propagate

❌ "REQUEST_DENIED"

Solution: Enable billing account

1. Go to Billing in Google Cloud Console 2. Link a billing account with valid payment method 3. Note: You get $200 free credits monthly
