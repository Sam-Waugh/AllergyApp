📱 How to Use These Icons

Brand Colors:
Primary Teal: #4A9B9B
Secondary Coral: #FF7F7F
Background: #F8FAFC
  1. Download each icon by clicking the download buttons below
  2. Replace the existing files in your frontend/assets/ folder:
    • icon.png → Main app icon (1024×1024)
    • adaptive-icon.png → Android adaptive icon (1024×1024)
    • splash-icon.png → Splash screen icon (400×400)
    • favicon.png → Web favicon (48×48)
  3. Run expo prebuild --clean to regenerate native assets
  4. Test your app with expo start
